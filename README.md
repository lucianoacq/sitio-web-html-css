# Sitio web con HTML y CSS

Sitio académico sobre **Breaking Bad**, desarrollado por Luciano Acquaviva. Presenta la historia de la serie, sus personajes y temporadas mediante páginas HTML independientes y estilos CSS compartidos.

## Páginas

| Página | Contenido |
| --- | --- |
| `index.html` | Portada y presentación breve de Walter White y Jesse Pinkman |
| `historia.html` | Historia de la serie, imagen y texto descriptivo |
| `personajes.html` | Fichas de personajes con imágenes y descripciones |
| `temporadas.html` | Resumen de las temporadas |
| `contacto.html` | Formulario visual con campos obligatorios |

## Tecnologías y conceptos

- HTML5: estructura semántica, navegación, imágenes, etiquetas y formularios.
- CSS3: tipografía, colores, espaciado, bordes, tarjetas y Flexbox.
- `normalize.css` para normalizar estilos entre navegadores.
- Archivos estáticos, sin JavaScript ni frameworks.

## Cómo verlo

**[Ver sitio publicado](https://lucianoacq.github.io/sitio-web-html-css/)**

Descargar o clonar el repositorio y abrir `index.html` en un navegador. También se puede abrir la carpeta en VS Code y ejecutar **Open with Live Server** desde `index.html`. No requiere instalación de paquetes ni un proceso de compilación.

## Alcance del trabajo

El formulario es una demostración visual: no tiene un servicio de envío de mensajes ni almacena consultas. El proyecto conserva el diseño académico original, sin media queries específicas para dispositivos móviles. Se corrigieron el idioma del documento y la asociación de etiquetas y campos del formulario al preparar el repositorio.

Las cinco páginas comparten navegación, estilos y una carpeta local de imágenes. Se comprobaron sus enlaces internos, las rutas de las imágenes y las etiquetas de los campos del formulario.
